## GitHub Pages deployment

This project will be deployed to GitHub Pages.

Configure Vite so it works both for a user site and for a project repository site.

Create a single configuration variable:

```js
const repoName = "YOUR_REPOSITORY_NAME";
```

Support:

```text
https://USERNAME.github.io/
```

with:

```js
base: "/"
```

and:

```text
https://USERNAME.github.io/REPOSITORY_NAME/
```

with:

```js
base: "/REPOSITORY_NAME/"
```

Use a routing approach compatible with static GitHub Pages.

Prefer `HashRouter` to avoid refresh-related 404 errors on nested pages. All navigation links must work correctly within the deployment base path.

Do not use hardcoded absolute paths for assets. Use Vite-compatible asset imports or `import.meta.env.BASE_URL` for files in the public folder.

Generate this deployment workflow:

```text
.github/workflows/deploy.yml
```

The GitHub Actions workflow must:

- Deploy when changes are pushed to `main`
- Install dependencies
- Build the Vite application
- Upload the `dist` directory
- Deploy to GitHub Pages
- Use the official GitHub Pages Actions flow
- Use minimum necessary permissions
- Be ready to run after GitHub Pages is configured to deploy from GitHub Actions
